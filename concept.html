Web 2.0

Web 2.0 is the conceptual state of the World Wide Web that we have experienced since the early 2000s (around 2004-2006, as a starting date). The term is by no means an official version number, but rather a representation of the stark contrast between our current Web landscape, and the landscape preceding it.

Web 2.0 is primarily defined by advancements in interconnectivity and internet distributed content. The previous version of the World Wide Web (Web 1.0) was built off static pages, and information being consumed similarly to reading a book. Now, though, there are various unique ways to both distribute and consume content through the web (think about reading an online textbook, versus clicking through a interactive website with pictures in order to receive the customized information).

User Generated Content (UGC)

User Generated Content (or UGC), put very simply, is anything a World Wide Web user creates and makes available for others, without being tied to a specific corporate context. Often times, UGC uses Web tools in order to make said content, but this is not necessary by definition.

Traditional definitions of User Generated content don’t include content made under corporations, such as Microsoft or Apple publishing a piece of software through the internet. However, the definition can be more loose depending on the situation.

There are still general guidelines on what makes User Generated material fit the role of content. The OECD (Organisation for Economic Co-operation and Development) classifies these forms of content in the increasingly digital age as possessing three key traits:

  • i) content made publicly available over the Internet
  • ii) content which reflects a certain amount of creative effort
  • iii) content which is created outside of professional routines and practices.

It is generally accepted that material published to the internet unaligned with these traits, is not true content. While existent, these types of materials are often adverse to the concept of the “participatory web”, and serve an alternate, more material purpose (such as making money).

Types of User Generated Content

User Generated Content is all around! It can range from many Web mediums, old and new!

  • Written - Texts, Blogs, Guides, Reviews, Posts, Forums, Chats, Stories, Articles, Archives, Code

  • Audio - Music, Podcasts, Voiceovers, Audio Simulations, Calls, Storytelling, Archives

  • Photographic - Photos, Memes, Graphics, Examples, Comparisons, Edits, Archives

  • Video - Education, Entertainment, Tutorials, Archives, Simulations, Broadcasts, Edits, Storytelling, Comparisons

  • File - Code, Website Structures, Open Source Software, Downloadable UGC, Mods, Plugins, Extensions, 3D Models, Configurations, Games, Archives, Data

  • Interactive - Websites, Databases, Games, Simulations, Social Networks, Wikis, Forums, Profiles, Search Engines, Virtual Intelligence, Moderation Tools

You may notice some overlap, and that's ok! User Generated Content spans these mediums and more, and almost always in conjunction! These are simplistic examples of the hundreds of different types of possible UGC.

UI, UX, and other User Based Workings

UX and UI stand for “User Experience” and “User Interface” respectively. Due to users now playing a crucial role in both the development and the upkeepings of cyberspace, distributors for the internet needed specialized workings to keep the open web open to everyone regardless of deep technical knowledge.

It is now a entire computer development profession to make sure that tools on the internet that create or access User Generated Content make logical sense to someone who doesn’t understand internal computing. This concept is also called “Abstraction”, in which a process is made multiple times more simple to understand by relying only on what it does instead of how it does it. “Uploading” something using a dropbox or file selection screen is a great example of this, since you are distributing your generated content without actually having to know how the data is processed and transmitted.
